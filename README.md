# Catálogo Visual | Portfolio Studio

## Descripción
Proyecto web desarrollado con HTML, CSS, PHP y MySQL.

La página presenta un catálogo visual organizado por categorías, permite explorar contenido destacado y cuenta con un formulario de contacto con almacenamiento en base de datos. También incluye modo claro y oscuro para personalizar la experiencia del usuario.

## Tecnologías utilizadas
- HTML5
- CSS3
- PHP
- MySQL
- PDO

## Instrucciones de uso
1. Importar el archivo `database.sql` en MySQL o phpMyAdmin.
2. Configurar los datos de conexión en `php/db.php`.
3. Colocar el proyecto en un servidor con soporte PHP y MySQL.
4. Abrir `index.php` desde localhost o hosting.

## Estructura del proyecto
- `index.php` → página principal
- `coleccion.php` → catálogo y filtros
- `contacto.php` → formulario de contacto
- `sobre.php` → información del proyecto
- `php/` → conexión y componentes reutilizables
- `css/` → estilos
- `database.sql` → estructura y datos de la base de datos
